# ● чат

Минималистичный одностраничный чат с нейросетью. Работает с любым OpenAI-совместимым API (`/v1/chat/completions`), ответы стримятся в реальном времени.

## Запуск

1. Скопируйте `config.example.js` в `config.js` и подставьте свои значения:
   - `apiUrl` — адрес API (например, `https://example.com/v1`)
   - `token` — токен доступа
   - `model` — модель (по умолчанию `auto`)
2. Откройте `index.html` в браузере или поднимите статический сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Настройки также можно поменять прямо в интерфейсе (кнопка ⚙) — они сохраняются в localStorage браузера и имеют приоритет над `config.js`.

## Возможности

- стриминг ответов (SSE)
- история диалога в рамках сессии
- светлая и тёмная темы (◐)
- подсветка блоков кода и `inline`-кода
- Enter — отправить, Shift+Enter — новая строка
- очистка диалога (✕)

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | стили, темы через CSS-переменные |
| `app.js` | логика чата и стриминга |
| `config.js` | локальные настройки (в `.gitignore`) |
| `config.example.js` | шаблон настроек |
